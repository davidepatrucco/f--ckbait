# Icone dell'estensione

Le icone dovranno essere create nei seguenti formati:
- icon-16.png (16x16 pixel)
- icon-48.png (48x48 pixel) 
- icon-128.png (128x128 pixel)

Tema suggerito: un limone stilizzato con elementi che richiamano il riassunto/testo.

Per ora puoi usare icone placeholder o creare delle icone semplici con uno strumento di grafica.
